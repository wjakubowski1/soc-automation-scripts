# VirusTotal IoC Checker

A Python-based tool developed for automated security telemetry enrichment and threat intelligence analysis.

## What does this script do?

This script automates the process of checking suspicious Indicators of Compromise (IoCs). By integrating with the VirusTotal API, it retrieves real-time reputation scoring for IP addresses or domains. This allows security analysts to quickly identify and verify malicious indicators without the need for manual, time-consuming lookups.

## How to run it?

1. Install the required dependencies (if applicable): `pip install requests`
2. Insert your personal VirusTotal API key into the script.
3. Run the script: `python vt_checker.py`
